# Priyadharshini S. — Portfolio

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Before publishing
- Add your own resume PDF as `assets/resume.pdf`.
- Confirm the contact details and skills are accurate.
- Replace the E-commerce Recommendation System GitHub profile link with the specific repository when the project is available.
- Check both Google Drive certificate links in a private/incognito browser.
- The PAPERLY button opens the Figma prototype, not a live website.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `my-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for GitHub Pages to publish and test the displayed URL.

No profile image is used in this portfolio.
